# CM Studio PRO

Repositório de releases e verificação de atualização automática do CM Studio PRO.

- O aplicativo verifica novas versões em `version.json` (branch `main`).
- Cada versão é publicada em **Releases**: baixe o `CMStudioPro_v4.8.exe` da release correspondente.
- O gerador de keys e os backups de código **nunca** são publicados aqui (contêm o segredo das keys).
